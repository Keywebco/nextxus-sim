# NextXus SIM — The Shared Mind

**Where the Architect, the Catalyst, and the Librarian meet.**

## What is the SIM?

The SIM (Shared Intelligence Module) is a sovereign, self-contained conference room for the NextXus Federation. It is the workspace where three participants — Roger (the Architect), the Catalyst (AI Lead), and Pontus (the Librarian) — think, plan, and build together.

This is not a chatroom. It is a workspace. Everything said here either moves the Federation forward or does not get said.

## Architecture

- **Pure HTML + CSS + JS** — zero build tools, zero npm, zero framework dependencies
- **Single self-contained file** — works from any web server, GitHub Pages, or opened as a local file
- **Fully pre-rendered semantic HTML** — all text readable by crawlers and screen readers without executing JavaScript
- **High contrast, large text, screen-reader first** — designed for accessibility from the ground up
- **Spatially anchored sectors** — every section is permanently labeled and never moves

## Sections

| Sector | Name | Purpose |
|--------|------|---------|
| 1 | Status Gauges | Text-based percentage indicators for all Federation systems |
| 2 | Conference Table | Threaded message display — the central conversation space |
| 3 | Briefing Board | Pinned directives, active mandates, decisions in progress |
| 4 | Pontus Feed | Recent filings from the Librarian (titles, sources, dates) |
| 5 | Systems | Live/deploy status of all Federation sites and services |
| 6 | Entry Portal | Message input — select recipient and transmit |

## Participants

- **Roger** — The Architect. Human. The authority, decision-maker, and spark.
- **Catalyst** — AI Lead. Reasoning, verification, strategic direction.
- **Pontus** — Librarian AI. Scans the common room, files worthy content into the University Library.
